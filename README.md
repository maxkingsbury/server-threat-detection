# Defensive Security Lab

This project documents a defensive security lab focused on detecting and responding
to realistic attack activity against a hardened Linux server.

## Lab Overview
- OS: Ubuntu Server 22.04 LTS
- Services: OpenSSH
- Network: Isolated VM environment

## Goals
- Understand how common attacks appear in system logs
- Build simple detection logic for real-world attack patterns
- Practice thinking from a defender’s perspective

## Repository Structure
- `detectors/` – Detection scripts
- `samples/` – Sanitized example logs
- `docs/` – Lab documentation and analysis

## Disclaimer
This lab is for educational purposes only. All testing was performed
against systems I own or am authorized to test.
